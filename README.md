Power BI — Анализ велосипедных поездок

Описание проекта

Интерактивный аналитический отчёт, разработанный в Microsoft Power BI для исследования велосипедных поездок.

Основные показатели

Общее количество поездок.

Средняя продолжительность поездки.

Среднее количество поездок в день.

Визуализации

Динамика количества поездок по месяцам.

Анализ поездок по дням недели.

Распределение поездок по часам суток.

ТОП-10 станций отправления.

Распределение поездок по типам подписки.

Интерактивные фильтры

Год.

Тип подписки.

Используемые инструменты

Microsoft Power BI Desktop.

Power Query.

DAX.

Интерактивные диаграммы и фильтры.

Цель проекта

Выявление закономерностей использования велосипедного транспорта, анализ активности пользователей и исследование распределения поездок по времени и типам подписки.
